# TrTree 前端设计与实现规范

> 参照 Windows WizTree：极简、专业、信息密度高、以树状图（Treemap）为核心。
> 纯原生 HTML/CSS/JS（ES modules），**禁止** npm 依赖、CDN、构建步骤、外部字体。
> 代码位置：`TrTree-fn/src/web/`，由 Go 二进制 `//go:embed` 内嵌。

## 0. 文件与职责

```
src/web/
├── index.html          # 页面骨架 + SVG 图标 sprite（内联）
├── css/app.css         # 全部样式（CSS 变量、暗色主题、响应式）
└── js/
    ├── api.js          # API 封装（统一错误、轮询）
    ├── host.js         # fnOS 桌面壳桥接（openFileManager/openFile 等，Trim App 协议）
    ├── format.js       # 字节/百分比/时间/数字格式化
    ├── treemap.js      # 树状图：布局算法 + Canvas 渲染 + 交互（导出 class TreemapView）
    ├── table.js        # 虚拟滚动表格（可排序、分页/过滤）
    └── app.js          # 应用状态机、视图、事件绑定、轮询
```

接口契约见 `docs/API.md`，必须严格对齐；后端未就绪时用 `tools/mock-server.js` 预览。

**打开文件管理器**：微应用运行在桌面壳 iframe 里，必须调用宿主桥接
`openFileManager(path,{isAdmin})`（见 `host.js`），不能用 `window.open` 拼 hash 路由。
桥接不可用时（例如本地直接用浏览器打开）退化为复制路径 + 提示。

## 2. 页面结构

```
┌───────────────────────────────────────────────────────────────┐
│ Header 56px: [logo] TrTree 磁盘分析   路径输入 [浏览][扫描]  │
│                                      [导出▾] [GitHub?] [状态] │
├───────────────────────────────────────────────────────────────┤
│ (空状态) 存储空间卡片网格 + 最近扫描                            │
│ (扫描中) 进度面板（大进度条 + 计数 + 当前路径 + 取消）          │
│ (结果)                                                        │
│  面包屑栏: [↑] / vol1 / 1000 / Photos      [视图切换]         │
│  ┌──────────────────────────────┬────────────────────────┐   │
│  │ Treemap Canvas               │ 侧栏 300px             │   │
│  │                              │ 当前目录详情            │   │
│  │                              │ 扩展名分布              │   │
│  │                              │ 当前目录最大项          │   │
│  └──────────────────────────────┴────────────────────────┘   │
│  底部面板 320px: [文件列表][大文件 Top][搜索结果][错误]        │
│  状态栏: 扫描于 xx:xx · 1,234,567 文件 · 3.2 TB · 用时 12.3s │
└───────────────────────────────────────────────────────────────┘
```

### 2.1 Header

- 左侧：内联 SVG logo（方块 Treemap 图案，24×24）+ 标题 `TrTree`，副标题 `磁盘空间分析`（弱化）。
- 中间：路径输入框（占位 `/vol1`），支持回车扫描；右侧「浏览」按钮打开目录选择弹窗；「扫描」主按钮。
  扫描运行中：按钮变为「停止」危险色按钮，点击调用 cancel。
- 右侧：导出下拉（CSV / JSON，需有完成扫描）、状态点（绿=空闲/黄=扫描中/红=错误）+ 文案。
- 路径输入框有 `/` 快捷键聚焦（输入框外）。

### 2.2 空状态

- 大标题「分析你的存储空间」，副标题「像 WizTree 一样，秒级看清每个目录、每种文件占用了多少空间」。
- 存储空间卡片网格（每行 2–3 张）：
  - 顶部：图标 + 「存储空间 1」+ 挂载路径；
  - 中间：大号已用容量 + `/ 总量` + 使用率百分比；
  - 底部：横向使用率条（>85% 红色，>70% 黄色，否则蓝色）；
  - 右侧或底部「分析」按钮；`accessible=false` 时禁用并提示。
  - 系统盘卡片样式弱化。
- 「最近扫描」列表（最多 5 条）：路径、大小、文件数、相对时间、状态；点击「重新分析」直接 POST 扫描。
- 底部提示条：「应用以只读方式分析磁盘，不会修改或删除任何文件。需要访问全盘时请以管理员身份使用。」

### 2.3 扫描中

- 居中卡片：
  - 大号百分比 + 旋转/条纹动画进度条（扫描总量未知，使用“已扫描文件数/字节数”动态进度，不显示假百分比；用无限条纹动画）；
  - 四宫格计数：已扫描文件、目录、累计大小、耗时；
  - 当前路径（等宽字体，单行省略，可 tooltip）；
  - 「取消扫描」按钮；
  - 若扫描超过 3s，显示提示「正在遍历目录，数据量较大时可能需要数分钟」。
- 进度轮询 400ms；`status` 变化时切换视图。

### 2.4 结果主视图

**面包屑**：`↑ 上级` + 从扫描根到当前节点的每一级（可点击）；根节点名称 = 扫描路径 basename（`/` 显示 `/`）。右侧显示当前目录大小 / 占扫描根百分比。

**Treemap 画布**：
- 占满左侧区域，`ResizeObserver` 自适应，devicePixelRatio 高清渲染。
- 布局：squarified treemap，子项按 size 降序；单层平铺（不做嵌套小格子，避免视觉噪音；drill-down 代替）。
- 每个 tile：2px 间隔、1px 内描边；颜色按类型/扩展名分类；hover 时白色描边 + 提升亮度；选中时 2px 白色描边 + 外发光。
- tile 内文字（仅当宽高足够）：名称（截断）+ 大小（如 `1.2 GB`）；字号 12px/11px；文字阴影保证可读。
- 空目录/极小项：不渲染文字。
- 顶部浮层（画布内左上）：当前目录名 + 子项数 + 排序说明；右上角小按钮：放大/缩小？不需要。提供「显示前 N 项」提示。
- 子项超过 4000：取前 4000，剩余聚合为「其他 N 项」（灰色，不可点击，tooltip 显示剩余总大小）。
- Hover tooltip（跟随鼠标，边界翻转）：名称、完整路径、大小、占父目录百分比、条目数、修改时间。
- 单击：选中（更新侧栏 + 高亮），双击目录：进入该目录；双击文件：无操作（或定位到底部列表）。
- 单击空白：取消选中。
- 键盘：Backspace 返回上级；Enter 进入选中目录。

**侧栏**：
1. **当前目录卡片**：名称、完整路径（可复制，点击复制并 toast）、大小、占用、条目数、修改时间、占扫描根比例条。
   - 若为目录：按钮「在列表中查看」「进入目录」；若为文件：「所在目录」。
2. **扩展名分布**：Top 8 + 「其他」，每行：色点、扩展名、大小、占比条。点击某扩展名 → 底部列表按扩展名过滤（通过 `q` 参数？API 不支持 ext 过滤，可用前端二次过滤当前子项；不强制）。
3. **最大子项**：当前目录前 5 大子项，点击选中并定位。

**底部面板**：
- Tab：文件列表 | 大文件 Top 100 | 搜索结果 | 错误。
- 文件列表：
  - 工具栏：过滤输入（`q`）、类型下拉（全部/文件/目录）、排序说明、刷新图标。
  - 表格列：名称（含图标+颜色条）、大小、占用、占父级、条目数、修改时间。
  - 默认按大小降序；点击表头切换排序（服务端 `sort`/`dir`）。
  - 行高 34px，虚拟滚动；单击选中并同步 treemap；双击目录进入。
  - 空/加载/错误状态。
  - 行内名称前显示类型图标（目录/文件/链接）。
- 大文件 Top：调用 `/top?limit=200`，列：排名、名称、路径、大小、修改时间；点击「定位」跳转。
- 搜索结果：输入框 + 类型/最小大小过滤，300ms 防抖；结果表带完整路径；点击定位。
- 错误：分页表格，展示路径+错误。
- 面板高度可拖拽（300–520px），默认 320px；折叠按钮。

**状态栏**：扫描根、文件数、目录数、总大小、扫描耗时、「重新扫描」链接。

## 3. 目录选择弹窗

- 模态：顶部路径面包屑 + 输入框，主体目录列表（图标、名称、修改时间），右侧快捷根列表（存储空间/用户目录/根目录）。
- 双击进入，单击选中；底部「选择当前目录」。
- 加载中骨架；错误提示（无权限）。
- Esc 关闭；点击遮罩关闭。

## 4. 交互与状态机

`appState = { phase: 'empty'|'scanning'|'result'|'error', volumes, context, scan, nodeId, node, ancestors, children, sort, tab, selection }`

- 初始化：`GET /api/context` + `GET /api/volumes`。
- 开始扫描：POST → 进入 scanning → 轮询 progress；完成 → GET result（tree?node=0&depth=1）→ 进入 result；失败 → error toast + 空状态。
- drill-down：`GET tree?node=X&depth=1`，更新 node/children/ancestors，treemap 重绘，底部列表刷新。
- 选中节点：只更新侧栏与高亮，不重新请求（child 数据已含）。
- 搜索结果定位：`GET locate?node=ID` → 更新 ancestors → 请求该节点的父目录 tree → 选中该节点；若节点是目录，可选择直接进入。
- 路径输入直接扫描任意路径（后端校验）。
- 浏览器前进/后退：使用 `history.pushState` 记录 `?scan=<id>&node=<id>`，popstate 时恢复（可选，尽量实现）。

## 5. 树状图布局算法（squarified）

纯函数，便于测试：

```js
// rows: [{value, ...}]，value 降序
// 返回 [{...row, x, y, w, h}]
export function squarify(items, x, y, w, h) { ... }
```

要求：
- 标准 Bruls/Huizing/van Wijk squarified treemap。
- 处理 0 值、单元素、宽高为 0、数值溢出。
- 先按 value 降序排序（调用方保证），总和归一化。
- 结果覆盖整个矩形且不重叠（允许 1e-6 误差）。
- 用 `treemap.js` 内部测试页面验证：`/treemap-test.html` 可选，不打包。

颜色：

## 6. 性能与稳健性

- 单次渲染 tile 上限 4000；Canvas 绘制循环内不做 DOM 操作。
- 表格虚拟滚动：只渲染可视区域 ±10 行；100k 行不卡顿。
- 所有 fetch 有超时（15s）与错误 toast；轮询失败最多重试 3 次后停止并提示。
- 长路径、超长文件名省略（CSS + title）。
- 大数字本地化（`Intl.NumberFormat('zh-CN')`），容量使用 1024 进制（B/KB/MB/GB/TB/PB，保留 1–2 位）。
- 禁止 `innerHTML` 拼接用户文件名（XSS）；统一 `textContent` 或转义。
- 无外部请求（离线可用）。

## 7. 空/错误/边界

- 扫描路径不存在/无权限：toast + 留在当前视图。
- 空目录：treemap 显示「此目录为空」占位。
- 扫描被取消：结果可用，顶部黄色提示条「扫描已取消，结果可能不完整」。
- 错误数 >0：状态栏显示「N 个目录无法读取」，点击切到错误 Tab。
- 扫描根为 `/`：面包屑显示 `/`，不显示重复的 root 名。
